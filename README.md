# MYP Skin & Body — Sitio web

Rediseño moderno y adaptable a móviles para MYP Skin & Body.

## Requisitos

- Node.js 22.13 o superior
- npm

## Abrir y editar el proyecto

```bash
npm install
npm run dev
```

Después abre la dirección local que aparece en la terminal.

## Archivos que editarás con más frecuencia

- `app/page.tsx`: textos, precios, teléfono, correo, enlaces y contenido de servicios.
- `app/globals.css`: colores, tamaños, distribución y diseño responsive.
- `app/layout.tsx`: título y descripción para buscadores.
- `public/images/`: coloca aquí las fotografías del negocio.
- `GUIA-DE-EDICION.md`: instrucciones detalladas para reemplazar imágenes y contenido.

## Subirlo a un repositorio nuevo de GitHub

Descomprime el proyecto, abre una terminal dentro de su carpeta y ejecuta:

```bash
git init
git add .
git commit -m "Sitio web MYP Skin and Body"
git branch -M main
git remote add origin https://github.com/TU-USUARIO/TU-REPOSITORIO.git
git push -u origin main
```

Sustituye `TU-USUARIO` y `TU-REPOSITORIO` por los datos de tu repositorio.

## Comprobar los cambios

```bash
npm run build
```

## Nota sobre el formulario

El formulario muestra la experiencia completa en pantalla, pero debe conectarse a un servicio de formularios, CRM, correo o plataforma de reservas para enviar solicitudes reales.
